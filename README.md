# 🚖 Urban Taxi Fare Prediction

## 📌 Overview
This project predicts urban taxi fares using Machine Learning and Streamlit.

## 🔧 Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## 📊 Features
- Taxi fare prediction
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Machine Learning model training
- Interactive Streamlit UI

## 📁 Files
- Tripfare.py → Main ML model code
- Urbantripfare.py → Streamlit application

## 🚀 Future Improvements
- Real-time fare prediction
- API integration
- Deployment on cloud platforms
